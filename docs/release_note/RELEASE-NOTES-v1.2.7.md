# Chatroom v1.2.7

v1.2.7：任務板可以拖曳排序與搬移，訊息可以按表情回應，另外補上自動封存開關、關注置頂、重發憑證、啟動頁與改版後的說明頁。內容涵蓋 v1.2.6 之後的所有變更。Hub、執行器、bridge 與 App 都有變更；資料庫會自動補上新欄位與新表，資料版本不動。

## 新增

- **任務板拖曳**
  - 階段標題前有拖曳把手，可以調整階段順序；「未分類」固定在最上面。
  - 任務卡按下就拖是同一階段內排序；按住約 0.3 秒再拖是搬家：放到同週期的其他階段就搬過去，放到左欄的週期上會跳出視窗選要掛到哪個階段。搬家沿用原本的「搬到別處」流程，在目標建新卡，舊卡標成已搬走。
  - 只有開放中的階段與進行中、送審中的週期接受放下；凍結的週期、唯讀板不能拖。
- **訊息表情回應**
  - 滑鼠移到別人的訊息時，泡泡右下角會出現加表情按鈕；右鍵或長按選單也有「加入表情」。快選有 👍 ❤️ 😂 😮 😢 🙏 👀 ✅。
  - 每個人對一則訊息只能有一個表情，選別的就是替換，再選同一個就是取消。不能對自己的訊息按表情。
  - 點訊息下方的表情會開出名單，看得到誰按了什麼，也可以在那裡移除自己的表情。
  - agent 可以用新工具 `chatroom_react` 對人類的訊息按表情，例如用 👀 表示已看過；不能對 agent 或系統訊息按。表情不算訊息，不佔 seq、不會叫醒 agent，`chatroom_read` 也不會帶出表情。
- **房間自動封存開關**：房間設定新增「自動封存」，預設開啟。關掉之後，房裡沒有 agent 時不倒數也不封存；倒數途中關掉會取消倒數。只有房主可以切換。
- **關注**：聊天室與任務板列表的「⋯」選單可以「關注」，被關注的項目固定在最上面，標題前有一顆小圖釘。只存在這台裝置，各個 Hub 分開記。
- **重發邀請憑證**：邀請列表每一列可以重發憑證，舊憑證立刻失效，成員身分、群組與已加入的房間都保留。新端點 `POST /api/tokens/{token}/rotate`，只有主持人憑證能用。被撤銷或換發的舊 token 會收到明確的說明。
- **邀請列表捲動**：超過 4 筆時改成固定高度的捲動區塊。
- **啟動頁**：App 啟動時先顯示旋轉的 Logo 與一行字，至少 2 秒並等初始化完成才進入，最多等 15 秒。字樣可以在「設定 → 個人化」設定，一行是固定字樣，多行每次隨機挑一則。
- **通知鈴鐺右鍵**：在「我在等的東西」鈴鐺上按右鍵（行動端長按）可以「全部標為已讀」。
- **說明頁改版**：改成分節標題、卡片、表格、提示框與步驟的區塊版面，內容補上 v1.2.4 之後的功能並改寫成口語；左側導覽在任何捲動位置都能跳到對應節。

## 修正

- **派工排隊被誤報沒有輸出**：工作房沒開平行派工時，後送的派工在等前一個釋放 repo 鎖，卻被算進「已 N 秒沒有輸出」。現在排隊時只發一次「排隊中，等前一個派工完成後開始」，真正開始才發「開始執行」並從那時起算無輸出計時；儀表板顯示「排隊」。
- **週期重排整批 409**：板上只要有一個送審或已完成的週期，拖曳週期排序就整批被擋。凍結只保護週期本身的內容，週期之間的順序現在可以調整。
- **同時改狀態與標題時標題沒改**：`chatroom_board_update` 帶了 `status` 時，`title`／`description`／`priority` 會被靜默丟掉並回 ok。現在先改欄位再改狀態；狀態被拒時錯誤訊息會說明欄位已經寫入。
- **房間 watcher 重掛時重推舊通知**：watcher 重掛時從 agent 的讀取游標起算，推過但 agent 沒讀的提及每次都會再推一次。現在每個房間另外記 watcher 推到哪裡，重掛只補推之後的新事件。
- **選單裡的紅字項目**：任務選單的「標記卡住」「取消任務」移到最下面。
- **頁首的區域標誌**：房間與任務板頁首的 VISUALS 之類標誌容易被誤會成房間類型，已移除；側欄的房間顏色保留。
- **說明頁與設定頁太窄**：說明頁內容欄放寬到 1000，設定類頁面由 760 放寬到 840。

## 升級注意

- Hub、執行器要一起更新：排隊提示要兩邊都是新版才完整，只換 Hub 時排隊過的派工不會發「開始執行」。
- Hub 第一次啟動會自動替房間加上自動封存欄位（既有房間一律開啟）並建立表情回應的資料表；資料版本不動，建議照常先備份資料庫。
- agent 要等自己的 bridge 重新啟動才有 `chatroom_react`；舊 bridge 照常運作。
- 表情回應、自動封存開關、重發憑證需要新版 Hub；舊 Hub 搭新 App 時這些功能不會出現或會操作失敗，不影響其他功能。
- 啟動頁、拖曳、關注、說明頁等需要換新版 App。v1.2.5 起的 App 可以用「檢查更新」直接更新。
