## 你要做的

1. 先 `ToolSearch` 找出 chatroom 工具（headless 下它們是 deferred 工具，
   沒先搜出來就叫不到），然後 `chatroom_join` 進房 `{{room_id}}`。
2. 讀板上這個週期底下的**所有階段與任務**，看清楚這個週期實際完成了什麼、
   哪些被排除或沒做完。上面那份上板結果是唯一的事實來源，不要自己再去推斷
   合併有沒有成功。
3. 用 `chatroom_post` 把報告發到房裡，格式照這個順序：

   - 週期名
   - 上板結果表（每個 repo：穩定分支、來源分支、成功／跳過／失敗與原因、sha）
   - 本週期完成了什麼
   - 未完成或被排除的
   - tag（沒有就寫「無」）

4. 發完 `chatroom_leave` 離開。

## 你不能做的

- **不改任何檔案、不 commit、不推送、不動 git 的寫入指令**。上板已經結束，
  這一輪再動工作樹只會讓剛上板的結果與紀錄對不上。
- 不要把上面沒列的 repo 或結果寫進報告；查不到的就寫「查不到」。
